# LeadGen — AI-Powered Job Discovery & Application Automation Platform

LeadGen is an AI-powered, multi-platform job discovery and application-automation platform that collects jobs from multiple sources, matches them to student profiles, assists with ATS-tailored applications, and tracks progress on a unified dashboard.

## Architecture Modules
1. **Module 1**: Scraping and Stealth Engine (388+ sources across 5 archetypes)
2. **Module 2**: Database and Ingestion Pipeline (PostgreSQL 16, pgvector, Celery, Redis)
3. **Module 3**: Backend REST API & AI Matching Engine (FastAPI, all-MiniLM-L6-v2)
4. **Module 4**: AI Resume Studio & Govt Document Lab (Typst, OpenCV, Pillow)
5. **Module 5**: Student Web Dashboard (Next.js 14/15, Modular Vanilla CSS)
6. **Module 6**: Form Autofill Co-Pilot (Chrome Extension Manifest V3)
